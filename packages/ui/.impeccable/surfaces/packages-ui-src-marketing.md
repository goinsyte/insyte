# Landing page (goinsyte.com)

Scope: the public landing, `packages/ui/src/marketing/`, served by `apps/marketing`. Visitor mode: Persuade.
Audience: a dropship operator running one or more Shopify stores. Job: understand that the Insyte-agent does the work
within rules the operator sets (agent-ready; autonomy, the customer agent and MCP marked binnenkort), and ask
for a beta invite. Action: Toegang aanvragen (primary), Inloggen (secondary). Proof:
only the mechanism, demonstrated with the console's own parts; real integration logos. No customers, metrics,
testimonials or trusted-by rows. Pricing from `plans.ts`, which is still an open decision.

## Direction contract

THESIS: De Blauwdruk as a page — a light drawing board with dark cyanotype chapters where the product proposes.
Refuses the centred-hero + three-card grid + logo marquee SaaS template.

OWN-WORLD: glacier/mist wrapper with an arc glow and drafting construction lines; abyss plates with the 32px
chalk grid, dashed construction rails, mesh-ink text; Drift mark; real vendor logos on mesh-ink tiles; General
Sans, Archivo only for figures; filled controls, no borders, no black.

STORY: the visitor sees the real console, reads that the day's work arrives pre-drafted, watches a ticket go from
melding to voorstel to verstuurd, sees every service it reads, and asks for an invite.

FIRST VIEWPORT: banner and full-width paper bar above an inset rounded abyss wrapper; one-line headline, one sentence, Toegang aanvragen +
Inloggen centred; the product window (dashboard with the queue plate) rising from the bottom edge and tilting
flat as you scroll.

FORM: code-led, user-pinned direction "Light wrapper, dark chapters". seed: none (unavailable)

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
